📖 How Server-Sent Events (SSE) Work Under the Hood

data: <payload>

The message content. Can be plain text or serialized JSON. Consecutive data lines are joined with newline characters.

event: <eventName>

Custom event names. Allows the browser to dispatch targeted events via addEventListener(name, callback).

id: <uniqueId>

Associates a monotonic event ID. The browser automatically stores this and sends it back in Last-Event-ID on reconnection.

retry: <milliseconds>

Tells the client how long to wait before attempting an automatic reconnect if the HTTP connection is interrupted.

: <comment>

Lines beginning with a colon are comment frames, used for heartbeat keep-alive pings to defeat proxy timeouts.
